# Maquette de l'interface GCC Meeting (validée le 12/11/2026)

Cinq écrans, dans le style de l'application GCC Louange (voir docs/TEMPLATE.md, charte GCC).
Chaque écran existe en HTML statique (ouvrable dans un navigateur) et en PNG.

1. `1-nouveau-compte-rendu` — dépôt de fichier / coller des notes / enregistrer ; catégorie, groupe, date, titre ; participants (toucher = absent).
2. `2-apercu-et-corrections` — aperçu du compte-rendu ; volet « Corriger » (discussion avec l'IA, « Seulement ici » / « Retenir comme règle »), « Transcription », « Détails » ; exports PDF, PNG, texte WhatsApp.
3. `3-comptes-rendus` — historique : recherche, filtres par catégorie, état (en cours, prêt, erreur).
4. `4-annuaire-et-groupes` — groupes en cartes, volet de modification, recherche dans l'annuaire, ajout d'un nom inconnu.
5. `5-regles-apprises` — noms corrigés, règles de rédaction activables, glossaire.

Les données affichées viennent des essais réels, sauf la « Réunion de la régie » en cours (exemple d'état d'attente).
