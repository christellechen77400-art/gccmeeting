# Modèle de compte-rendu (validé le 10/11/2026)

Exemples de référence : `reference/exemple-cr-gcc.png`, `reference/exemple-cr-musiciens.png`, `reference/bandeaux.png` (+ fichiers HTML sources).

## Format
- A4 portrait, une seule page si possible. Export PDF + PNG (×2 pour être net sur iPhone).
- Blocs vides : non affichés.

## Charte (reprise de la présentation Campus inter-église)
| Rôle | Couleur |
|---|---|
| Fond | `#F4EEE6` (crème) |
| Cartes | `#EAE0D2` (beige) |
| Bandeau, bloc mis en avant, texte | `#2E2118` (brun foncé) |
| Accent | `#B4552F` (brique) |
| Secondaire | `#6E7B5C` (sauge) |
| Texte secondaire | `#6B5D50` |

Polices : titres **Caladea** (équivalent libre de Cambria), texte **Carlito** (équivalent libre de Calibri).
Pictos : au trait fin (style Lucide), une couleur, jamais d'emoji.

## Bandeau (en haut)
Fond brun foncé. À gauche : petit texte « Catégorie · sous-titre » dans la couleur de la catégorie, titre de la réunion, date (et participants). **À droite : la pastille de catégorie** (couleur + picto + nom + sous-titre).

| Catégorie | Couleur | Picto | Sous-titre par défaut |
|---|---|---|---|
| GCC | `#B4552F` brique | pousse | Coordination |
| Culte Franco | `#5E7487` bleu ardoise | note de musique | Louange (ou le pôle : Musiciens, Régie, Présidence) |
| EDD | `#6E7B5C` sauge | enfants | École du dimanche |
| DA | `#A86A7A` vieux rose | mallette | Direction artistique |
| Campus GCC | `#C48A3A` ocre | flamme | GCC |
| Autre | `#8C7B6B` taupe | bulle | sujet libre (ex. Campus inter-église) |

## Ordre des blocs
1. **Bandeau**
2. **À retenir** : 3 points maximum, chacun avec picto + titre + une ligne.
3. **Résumé par bloc** : les sujets de la réunion, en cartes (picto + titre + texte court, tags éventuels).
4. Rubriques optionnelles, selon la réunion :
   - **Bilan** (liste à puces)
   - **Objectif / décision principale** (bloc brun foncé mis en avant, avec étapes numérotées si utile)
   - **Nouveautés** (cartes en grille 2×2)
   - **Questions ouvertes**
   - **Prochaines étapes** (qui · quoi · quand)
5. Pied de page : « GCC · <catégorie> · <titre> » à gauche, date à droite.
