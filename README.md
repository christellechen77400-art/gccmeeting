# GCCMeeting

Comptes-rendus de réunion automatiques pour GCC (Grace Church, partie francophone).

Dépose un audio ou des notes dans le bon dossier Drive : GCCMeeting génère un compte-rendu PDF + PNG au modèle validé et te l'envoie par mail.

Pour l'instant, en local : `npm run app`, puis ouvre http://localhost:3000.

- Consignes de développement : [`CLAUDE.md`](CLAUDE.md)
- Spécification : [`docs/SPEC.md`](docs/SPEC.md)
- Modèle de compte-rendu : [`docs/TEMPLATE.md`](docs/TEMPLATE.md)
- Où on en est : [`docs/HANDOFF.md`](docs/HANDOFF.md)
